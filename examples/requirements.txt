# Requirements for ADEPT Examples
#
# This file contains dependencies for standalone example scripts.
# These examples work WITHOUT installing the ADEPT framework library.
#
# Installation:
#   pip install -r examples/requirements.txt
#
# Or create a virtual environment:
#   python3 -m venv venv
#   source venv/bin.sh  # On Windows: venv\Scripts\activate
#   pip install -r examples/requirements.txt
